# TuteDude MERN Stack – JavaScript: Loops

## Files Included
- `index.html` – Page that links the CSS and JavaScript files
- `style.css` – Basic styling
- `script.js` – JavaScript program with all the operations
- `README.md` – This file

## How to Run
1. Unzip the folder.
2. Open `index.html` in Chrome or Firefox.
3. Press F12 and open the **Console** tab to see the output.

## Operations Performed

| # | Operation | Control Structure Used |
|---|-----------|------------------------|
| 1 | Sum of first n numbers | `for` loop |
| 2 | Print table of n | `for` loop |
| 3 | Sum of all digits of a number | `while` loop |
| 4 | Check if Armstrong number | `while` loop + `if-else` |
| 5 | Check if prime number | `for` loop + `if` + `break` |
| 6 | Print all factors | `for` loop + `if` |

## Variables Used
| Variable | Purpose |
|----------|---------|
| `number` | Main number (153) used for digits, Armstrong, prime and factors |
| `n` | Count for the sum of first n numbers |
| `tableNumber` | Number whose table is printed |
| `sumOfN` | Stores sum of first n numbers |
| `digitSum` | Stores sum of digits |
| `armstrongSum` | Stores sum of digits raised to the power three |
| `isPrime` | True or false result of the prime check |
| `factors` | Text containing all factors |

## Sample Output (for number 153)
```
Number :- 153
Sum of its digits: 9
Is it an Armstrong number? Yes
Is it a prime number? No
Factors: 1, 3, 9, 17, 51, 153
```

## Concepts Used
- Variables
- `for` loop and `while` loop
- `if-else` conditions
- `%` (remainder) and `Math.floor()` to work with digits
- `break` to stop a loop early
- `console.log()` to display results
